# Minor-project(OCR)
Language translator using OCR
---------------------------------------

There is a .exe file which needs to be installed in the computer system (tesseract.exe). I cannot upload the .exe file directly, 
so I'm providing the downloading link from the official website.

*Link* : https://github.com/UB-Mannheim/tesseract/wiki

After going to the website click on << tesseract-ocr-w64-setup-5.5.3.20260724.exe (64 bit) >>.

This will download the .exe file directly on the computer. Run the .exe to setup the tesseract engine. 

Then you need to set the PATH for it in the PC's environmental variable.

Just create a new path and paste the file's absoulute path in the new variable.
